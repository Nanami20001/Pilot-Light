# SL25 Rev B 点灯诊断

## 未焊 LED 时：先用慢速 GPIO 测试

烧录 `build/sl25_gpio_probe.hex`，下载校验后拔掉 USB、松开 JP1，再插入。程序将 CH552 3脚 P1.5 置低约3秒、置高约3秒，持续循环。使用直流电压挡，黑笔接 TP2，红笔分别测 MCU 3脚和 D1 4脚 DIN 焊盘，观察两个位置均在接近 0 V 与接近 VCC 之间切换。供电正常时约为 0/5 V。

先验证万用表和电源：TP1/MCU 15脚应接近 USB 的5 V，MCU 16脚 V33应约3.3 V，D1 1脚供电应与TP1相同，D1 3脚地应接近0 V。若仍读出2.5 V/1.66 V，先用第二只表或已知电压源复核，暂不增加LED负载。

芯片输出翻转而DIN不翻转时，断电检查R3=330Ω及两侧焊点/走线、R4=100kΩ；芯片输出也不翻转时，先检查是否下载校验成功、JP1已释放并重新上电、引脚编号正确，再查供电和复位。

GPIO测试只验证应用执行和直流数据通路，不验证WS2812高速时序。这个程序也不进行USB应用枚举；烧录仍使用JP1进入ISP。编译命令：`./Makefile.ps1 -GpioProbe`。

## 焊接 LED 后：颜色循环测试

先烧录 `build/sl25_led_diagnostic.hex`，下载校验成功后拔掉 USB、松开 JP1/BOOT，再插入供电。

预期：低亮度红 → 绿 → 蓝 → 熄灭，每段约 1 秒，持续循环。无须启动电脑状态代理。

这个程序不包含 USB 应用协议，因此运行时不会出现 `Codex Status Light` HID 设备。需要再次烧录时，断电后短接 JP1 并插入 USB，进入 CH552 自带 ISP，识别后松开 JP1。

结果判断：

- 可以循环点亮：这套数据时序和 LED 接线在当前样板上可以工作，再烧录修正版状态灯程序并测试主机报文。
- 仍完全不亮：确认 JP1 已松开、应用已启动，再复核灯珠型号/方向、实际供电及 P1.5 到 DIN 的通路。仅凭不亮不能认定灯珠损坏。
- LED 可以亮但仍测出 2.5 V / 1.66 V：使用另一只万用表或已知电压源复核读数；本程序没有调整 5 V 或 V33 电压。

编译：在本目录运行 `./Makefile.ps1`，默认使用 `E:\SDCC\bin\sdcc.exe`。

固件使用 `../common/ws2812_ch552.h`，与修正版状态灯程序共用 WS2812 发送代码。已通过编译和机器码时序模型验证。实际波形及本程序的实物测试结果仍待记录。
